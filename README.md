# Customer-Purchase-Behavior-Analysis-Prediction
Project Overview

This project provides insights into customer demographics and shopping behavior.
The main goal is to analyze how customer characteristics influence purchasing decisions and to build a predictive model that estimates the purchase amount based on customer features.

By understanding key factors driving purchases, businesses can make better marketing, pricing, and customer engagement decisions.

🎯 Objectives

Clean and preprocess raw customer data.

Perform exploratory data analysis (EDA) to identify trends and correlations.

Train a regression-based predictive model to forecast purchase amounts.

Evaluate model performance and identify the most influential customer features.

🤖 Modeling Approach

The following regression models were evaluated:

Linear Regression

Random Forest Regressor

XGBoost Regressor

Performance metrics:

R² Score

RMSE (Root Mean Squared Error)

MAE (Mean Absolute Error)
